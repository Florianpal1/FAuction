# Changelog

## Unreleased

### Command framework replaced: ACF → Cloud

The commands no longer run on [ACF](https://github.com/aikar/commands), which is no longer maintained
and was pulled from a moving snapshot, but on [Cloud](https://cloud.incendo.org) 2.x.

**Nothing changes for your players or your permissions**: `/ah`, `/hdv`, the 13 command paths and the
15 permissions are identical, including the `fauction.admin.purge.hictoric` typo — correcting it would
break existing permission setups, and it is a separate job.

What does change:

- **`/ah help` looks different.** The help is generated by Cloud now, with its own layout. Its texts
  are still read from the language files, under the new `fauction.help` section.
- **`/ah help <query>`** shows the help for one command path.
- **`/ah admin reload` now reloads the messages too.** Under ACF the language file was only ever read
  at startup.
- **`/ah admin migrate` refuses a version it does not know**, and tab-completes the ones it does.
  Before, `/ah admin migrate 1.7.9` did nothing at all and still answered "you have migrated to
  version 1.7.9" — a success message for a database migration that never ran.
- **`/ah sell` refuses a price that is not a finite positive number** before touching your inventory.
  `NaN` used to slip past every price check (every comparison involving `NaN` is false), and
  `Infinity` only ever met a limit when a maximum price happened to be configured. The player gets the
  same "negative price" message as before.
- **Minimum server version is now Paper 1.16.5**, the first version whose API carries Adventure, which
  the new framework uses to send its messages. In practice the plugin already needed 1.16 for its hex
  colours.

### Language files

Language files are **versioned and updated automatically** now, like the other configuration files.
**No action is required.** On the first start:

- the keys of the previous command framework (`acf-core`, `acf-minecraft`) are removed;
- the messages that are still used are moved to `fauction.error.*`, keeping any text you had edited;
- the missing keys are added, including the `fauction.help` texts of the new help;
- a `lang_<code>.yml.bak` copy is left next to the file before it is rewritten for the first time.

If you use a language the plugin does not ship (`lang_de.yml`, for instance), none of your keys are
removed and the ones you have not translated fall back to the English texts.

`lang_zhcn.yml` gained the three keys it was missing (`max_price`, `clear_cache`, `migrate`) — those
messages were silently never sent on a Chinese server.

### Under the hood

- Cloud's Folia-aware preprocessor runs the handlers on the region thread of the player, and the
  suggestions are computed through Brigadier when the server has it, without the Bukkit scheduler.
- `minimizeJar` is off: Cloud resolves its parsers and handlers by reflection, and the minimizer would
  prune classes no direct call references — breaking one command path, at runtime only. The jar is
  bigger as a result.
